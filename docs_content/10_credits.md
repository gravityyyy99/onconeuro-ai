# Credits

*This project stands on other people's work.*

## Data

- **Brain Tumor MRI Dataset** by Masoud Nickparvar on Kaggle: https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset

## Methods

- **Transfer learning**, PyTorch's tutorial: https://docs.pytorch.org/tutorials/beginner/transfer_learning_tutorial.html
- **ResNet:** He, Zhang, Ren and Sun, *Deep Residual Learning for Image Recognition* (2015).
- **ImageNet:** the large photo collection that ResNet-18 first learned from.
- **Grad-CAM:** Selvaraju et al., *Grad-CAM: Visual Explanations from Deep Networks via Gradient-based Localization*: https://arxiv.org/abs/1610.02391

## Software

- **pytorch-grad-cam** by Jacob Gildenblat: https://github.com/jacobgil/pytorch-grad-cam
- PyTorch and torchvision, Streamlit, Altair, Pillow and NumPy.
