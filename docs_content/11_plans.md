# Future plans

*What would make this better.*

1. **Fine-tune the whole network** and report how much accuracy improves, especially for glioma.
2. **Use more varied data** from several sources so the model is not tied to one collection.
3. **Use several slices per patient** instead of one picture.
4. **Add an "I am not sure" answer** so the model can decline when a picture is unlike its training data.
5. **Calibrate confidence** so that "90%" really means right about 90 times in 100.
6. **Check fairness** across different groups once the data allows it.
7. **Try other networks** and compare them honestly.
8. **Explain mistakes** with a gallery of the hardest cases.
9. **Talk to experts.** Any step toward real use must involve doctors and proper trials.

Even if every item gets done, this will remain a learning project unless it goes through the process real medical tools go through.
